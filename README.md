# 商场扶梯启停巡检与封控复开平台

管理楼层扶梯的运行方向、启停时段、班前检查、急停测试、围挡封控、故障报修、
维修到场、复检审批与客流绕行提示。设备与人员均为演示数据，**零第三方依赖**
（Python 3.11 标准库 + 原生 HTML/CSS/JS）。

## 启动

```bash
./run.sh                       # 默认 http://127.0.0.1:8000
# 或
python3 -m escalator --port 8000
```

一条本地命令查看三个内置样例（正常开梯 / 控制柜跳停 / 复检退回，使用临时库）：

```bash
python3 -m escalator.demo
```

测试：

```bash
python3 -m unittest discover -s tests     # 29 个用例
```

## 页面（8 个标签页）

楼层设备图（↑/↓ 箭头标识方向，斜纹边界表示停梯围挡）、开梯清单（通过/失败/不适用
三态）、运行状态、封控计时、报修进度（流水线）、复检审批、客流绕行、事件查询。

设计：商场白 / 机械银 / 安全红；围挡为斜纹边界而非整块红；复检每项保留清晰三态；
**复开确认区**以红斜纹虚线框与普通操作明显隔开。

## 核心规则（均有测试覆盖）

- **班前检查**：梯级、梳齿板、扶手带、照明、急停装置五项每日必检，不允许缺项
  （`CHECK_INCOMPLETE`）或失败（`CHECK_FAILED`），急停功能测试须当日合格，全部合格才允许启动。
- **急停测试失败**：独立处理，立即停梯封控并自动建工单（`ESTOP_TEST_FAIL`）。
- **启动互斥**：两名值班员不能同时启动同一扶梯（`START_IN_PROGRESS`）。
- **版本控制**：方向/状态变更都会推进版本，启动、复开必须携带当前版本（`STALE_VERSION`）。
- **方向错误**：命令方向与当前设定不符独立拒绝（`WRONG_DIRECTION`）。
- **封控**：故障/急停/客流触发停梯封控，5 分钟内必须搭设围挡，超时独立告警
  （`BARRIER_OVERDUE`）；围挡斜纹显示，未审批不得撤除。
- **维修**：报修→派单→到场→完成，60 分钟 SLA，超时独立告警（`REPAIR_OVERDUE`），
  延期留痕（`REPAIR_EXTEND`）。
- **反复跳停**：24 小时内 ≥2 次跳停自动升级直接派单（`REPEAT_TRIP`）。
- **复检职责分离**：复检由巡检员提交（五项三态，漏项拒绝），**不能批准自己的复检**
  （`SELF_REVIEW`），由另一巡检员或主管审批；不合格或审批退回即返修。
- **复开阻断**：复检通过 + 围挡撤除 + 客流恢复 + 绕行撤销，缺一不可，
  强闯记录 `EARLY_REOPEN_BLOCKED`。
- **客服**：仅能发布/撤销绕行提示，任何设备操作均 403（`FORBIDDEN`）。

## 结构

```
escalator/
  db.py         SQLite 表结构（设备/检查/工单/复检/绕行/事件）
  clock.py      真实时钟 + 可推进 FakeClock（演示/测试）
  adapters.py   模拟控制柜（启停/急停/跳停）与客流读数（线程安全、可注入）
  services.py   全部业务规则
  scheduler.py  进程内任务：计划启停、维修超时、围挡宽限、跳停/客流轮询
  app.py        http.server：JSON API、静态页、照片上传
  web/          前端（index.html / app.css / app.js）
  demo.py       三个样例
data/           escalator.db（SQLite）与 photos/（故障照片，本地目录）
tests/          unittest 用例
```

设备详情弹窗提供"模拟适配器注入"（跳停、急停回路故障、客流密度滑块），
可在界面上直接演练封控→维修→复检→复开全流程。
